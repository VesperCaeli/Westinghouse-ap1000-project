# Public Source Register Supplement — Unit 3 RNS Preoperational / HFT Turnover Evidence

This supplement shares the global controlled `SRC-*` namespace. It establishes direct Unit-3 initial-test and HFT-era retrieval routes that can bridge construction-era RNS packages to the system configuration actually tested before fuel load. Test participation or successful inspection does **not** by itself reveal final spool geometry; drawing/package contents remain separate closure items.

The same reviewed-document population includes `APP-RNS-M6-001 Rev.13`. NRC also records test witnessing of 3-RNS-ITPP-501 with no findings. Carry this as the strongest public Unit-3 system-level preoperational-test package route. Recover the executed WO/procedure attachments, prerequisite boundary list, valve lineup, instrumentation, measured flows/pressures/temperatures, deficiency/resolution records and test-package closure to determine what final RNS configuration was actually tested. Do not infer that every RNS tag or every current post-amendment isometric was included unless the executed package prints it. |

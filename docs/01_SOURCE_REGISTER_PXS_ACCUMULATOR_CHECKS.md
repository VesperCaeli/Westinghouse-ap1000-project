| SRC-0502 | A | VOGTLE-3-CURRENT-PREOP-ITAAC | Southern Nuclear Unit-3 ITAAC Closure Notification `ND-20-0337`, Completion of ITAAC 2.2.03.12a.iv (Index 216), check-valve transfer-position verification | ADAMS `ML20287A408`, Enclosure pp.3-4; historical pre-completion cross-check `ML19161A102` | The completed Unit-3 closure notification explicitly identifies accumulator discharge check valves `PXS-PL-V028A`, `-V029A`, `-V028B`, and `-V029B`. For transfer-closed testing, the accumulator discharge lines were water-filled, the applicable accumulator level was 55-56%, its discharge isolation valve(s) were closed, one RNS train was recirculating the RCS with hot-leg level 48-50%, and the **PXS test panel** sequentially placed **RNS pressure on the downstream side of each individual accumulator discharge check valve**. The **respective upstream test connection** for each check valve was opened to depressurize the upstream side; the resulting differential pressure demonstrated transfer closed. The sequence was repeated for B-side valves `V028B` and `V029B` and documented in ITAAC Technical Report `SV3-PXS-ITR-802216`. The notification states these test flow paths are depicted on `SV3-PXS-M6-001`, *P&ID Passive Core Cooling System*, and that preoperational testing also demonstrated the transfer-open function. This is direct current Unit-3 evidence that dedicated test interfaces and a selectable PXS-test-panel/RNS pressurization path physically interface with each accumulator discharge check valve. It does **not** print the individual small-bore test-connection tags, valve/fitting population, exact routing, test-panel component tags, pressure value, or the physical series order of V028 versus V029. Recover the controlling Unit-3 P&ID and test package before canonicalizing those details. |

Possible explanations include an inspection package using a retained older revision, different document-effective dates, revision-history/configuration-control effects, or a citation error; none is promoted without the controlled revision history.

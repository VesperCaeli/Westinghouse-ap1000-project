# Public Source Register Supplement — RNS V002B / PV01 Family Bridge

This supplement shares the global controlled `SRC-*` namespace with the other `01_SOURCE_REGISTER*.md` files.

| Source ID | Authority | Configuration | Document | Locator / accession | Use |
|---|---|---|---|---|---|
| SRC-0465 | A | AP1000/VOGTLE-DESIGN-HISTORY | NRC AP1000 design-document review of safety-related RNS valve requirements against the PV01 motor-operated-valve specification | ADAMS ML112440588, design-document review narrative and reviewed-document list | NRC states that inspectors evaluated safety-related valve functional/design requirements and compared `APP-PV01-Z0-001`, *3 in. and Larger Motor Operated Gate and Globe Valves, ASME Section III Classes 1, 2 and 3*, against `APP-RNS-M3C-100`, *RNS Component Control Requirements*, to verify consistency. The same inspection identifies `APP-RNS-M3C-050` as the MOV functional-requirements document specifically covering RNS hot-leg suction isolation valves V001A/B and V002A/B. This is sufficient to treat PV01 as the design commodity/specification family applicable to the V001/V002 RNS MOV requirement set. It does **not** identify the individual PV01 datasheet, vendor/model, actuator model, or Unit-3 as-built serial for `RNS-PL-V002B`; `APP-PV01-Z0D-116` and the exact actuator subfamily remain unresolved until a primary tag-to-datasheet/as-built record is recovered. |
| SRC-0466 | A | AP1000/VOGTLE-QUALIFICATION-HISTORY | NRC seismic equipment-qualification inspection of Normal Residual Heat Removal System MOVs | ADAMS ML17226A034, ITAAC 2.3.06.05a.ii inspection, PDF p.41 and reviewed-document list | NRC explicitly identifies `RNS-PL-V001A`, the RCS inner hot-leg suction motor-operated isolation valve, as commodity `PV01`. For that RNS sample the inspectors reviewed `APP-PV01-VBR-011`, *Equipment Qualification Summary Report for Flowserve Flex Wedge Gate Valves with Limitorque Motor Operators*, and `APP-PV01-VBR-012`, the corresponding qualification data package. This is direct tag-specific evidence that one member of the V001/V002 hot-leg suction MOV set belongs to the Flowserve/Limitorque PV01 qualification family. It materially strengthens `APP-PV01-Z0D-116` / Flowserve-Limitorque as the candidate subfamily for the four V001/V002 valves, but it is **not** transferred to `RNS-PL-V002B`; paired/sibling inference remains prohibited until a V002B-specific current/as-built or tag-to-datasheet record is recovered. |
| SRC-0468 | A | VOGTLE-3-CURRENT-PUBLIC | NRC Unit-3 equipment-qualification/as-built inspection identifying the current PV01 valve-setup record | ADAMS ML22193A291, reviewed-document list, `SV3-PV01-VDR-000002`, *PV01 - Valve Information for Valve Set-up*, Revision 2 | Identifies a current Unit-3 controlled PV01 valve setup document in the same inspection record that reviews current Unit-3 PV01 qualification data packages. This is the highest-value current retrieval target for tag-to-datasheet mapping and valve/operator setup attributes such as actuator/motor identity, stem/gear data, torque/thrust settings, switch setup and related calculation or assembly references. The public inspection text does **not** expose the VDR rows or state that `RNS-PL-V002B` is contained in the document, so no V002B vendor/model/datasheet/setup value is promoted solely from this document identity. |
| SRC-0469 | A | VOGTLE-PV01-PROCUREMENT | NRC vendor/procurement inspection record for AP1000 safety-related valves | ADAMS ML16307A159, reviewed purchase-order list; cross-check ML20042E292 reviewed-document list | NRC explicitly identifies Westinghouse Purchase Order `4500319052`, dated 2009-09-28, to **Flowserve** for **98 AP1000 motor-operated valves (PV01) – Vogtle**. Later NRC inspection records identify `SV0-PV01-Z5-010`, *Change to Purchase Order #4500319052*, dated 2018-04-13, preserving the same controlled procurement lineage. Because `RNS-PL-V002B` is independently established as a PV01-design-family valve through SRC-0465, this is complete-population procurement evidence rather than paired-valve inference and supports **Flowserve as the Vogtle PV01 prime valve supplier/vendor family**. It does not establish `APP-PV01-Z0D-116`, the exact Flowserve model/serial, the installed Unit-3 valve serial, or a Limitorque actuator model for V002B; those remain tag/datasheet/setup-specific closure items. |
| SRC-0470 | A | VOGTLE-PV01-PROCUREMENT-HISTORY | NRC Vendor Inspection Report 99901356/2012-201, Flowserve Corporation | ADAMS ML12275A341, report pp.10-11 and attachment pp.34-36 | NRC verified Flowserve's AP1000 valve design-control process and the translation of Westinghouse procurement requirements into Flowserve specification sheets, valve drawings, sales-order control sheets, procedures, analyses and calculations. The reviewed-document attachment reaches inside the **Vogtle** PV01 procurement chain by tying Westinghouse PO `4500319052` to Flowserve PO `110813`, internal SO `911175`, supplier code `103250`, and Aruna Alloy Steels, Madurai, India. It identifies receiver `234167` for item `911175-11` as a gate casting and receiver `234606` for the same item as two bonnet castings. An Aruna material certificate is listed for a gate valve under `SO 91175-11` with traceability code `M4393`, `SRL7`; the one-digit discrepancy between `911175-11` and `91175-11` is retained as an unresolved source-identifier reconciliation rather than silently normalized. This source creates concrete vendor-internal retrieval keys for the Vogtle PV01 order but **does not map item -11, M4393/SRL7, any casting/bonnet, any Flowserve serial, or any material heat to RNS-PL-V002B or APP-PV01-Z0D-116**. Promotion requires a Flowserve/Westinghouse order-control, QR/CoC, VQQ/VDR, datasheet, or as-built record that explicitly closes the item-to-datasheet/tag bridge. |

# Public Source Register Supplement — Unit 3 RNS Site Topology Extended

This supplement shares the global controlled `SRC-*` namespace with the other `01_SOURCE_REGISTER*.md` files. It adds site-work-package and generic line-function evidence that helps distinguish the B-train suction reconstruction from adjacent RNS discharge and cross-connect piping.

| Source ID | Authority | Configuration | Document | Locator / accession | Use |
|---|---|---|---|---|---|
| SRC-0720 | C | VOGTLE-3-RNS-PLW015-COISOMETRIC-LINES | Georgia Power / Bechtel Vogtle 3&4 Construction Completion Agreement Exhibit V, in-progress work packages | Public 2017 inventory, `SV3-RNS-P0W-ME5495` | The Unit-3 construction inventory explicitly maps work package `SV3-RNS-P0W-ME5495` to site isometric `SV3-RNS-PLW-015` and line numbers `RNS-PL-L005`, `RNS-PL-L029`, and `RNS-PL-L080`. Use this as a direct co-isometric constraint: these three line numbers occur on the same site isometric/work package. It does **not** prove that the three lines directly connect to one another, does not identify which train or valve each local segment contains, and does not print V002B. Recover PLW-015 itself before promoting branch order, fittings, valve placement or exact connectivity. |
| SRC-0721 | B | AP1000-WESTINGHOUSE-RNS-IRWST-SUCTION-LINE-FAMILY | Westinghouse AP1000 European Design Control Document `EPS-GW-GL-700` Rev.1, Table 2.3.6-2 | Section 21.2.3.6, Table 2.3.6-2 | The generic AP1000 RNS line table identifies `RNS-L029A/B` as the **RNS suction line from IRWST**. Combined with the Unit-3 PLW-015 co-isometric mapping, this proves PLW-015 contains at least one RNS hot-leg/pump-suction-family line (`L005`) and one IRWST-suction-family line (`L029`) on the same drawing package. Treat this as a retrieval clue for a suction/cross-connect region, not as proof of a specific tee, valve, or direct L005↔L029 connection. |
| SRC-0722 | C | VOGTLE-3-RNS-B-DISCHARGE-SITE-ISOMETRICS | Georgia Power / Bechtel Vogtle 3&4 Construction Completion Agreement Exhibit V | Public 2017 work-package inventory: `SV3-RNS-P0W-ME5498`, `ME5502`, `ME5503`, `ME5505` | Public Unit-3 work-package records identify additional B-side RNS site isometrics and line populations: `ME5498` → `SV3-RNS-PLW-182` on `L017-L018B`; `ME5502` → `SV3-RNS-PLW-191` on `L018B`; `ME5503` → `SV3-RNS-PLW-192` on `L018B`, `L019B`, `L067B`; and `ME5505` → `SV3-RNS-PLW-198` on `L018B`, `L066B`. Use these records to separate the downstream B-train **discharge/DVI/CVS-return region** from the V002B suction reconstruction and to recover pump-discharge-side geometry later. They are not evidence for V002B suction placement. |
| SRC-0723 | B | AP1000-WESTINGHOUSE-RNS-B-DISCHARGE-FUNCTIONS | Westinghouse AP1000 European Design Control Document `EPS-GW-GL-700` Rev.1, Table 2.3.6-2 continued | Section 21.2.3.6, pp.21-218/219 | The generic line table identifies `RNS-L017B` and `RNS-L018B` as the B-train discharge path from containment isolation valve `RNS-PL-V013B` to the RCS pressure-boundary isolation valve `RNS-PL-V015B`. It separately identifies `L019B` as discharge from the RCS pressure-boundary isolation valve toward the reactor-vessel DVI path. Use this to classify the Unit-3 PLW-182/191/192/198 work packages as **non-suction** geometry and to prevent those site line numbers from being mixed into the V002B suction sequence. Exact Unit-3 valve placement, local branch sequence, L066B/L067B functions and final DVI/CVS interfaces still require current site drawings. |

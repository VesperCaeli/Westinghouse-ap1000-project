# Public Source Register Supplement — RNS LTOP Implementation Constraints

This supplement shares the global controlled `SRC-*` namespace. It separates final Vogtle dual-relief licensing constraints from the pre-amendment single-relief numerical basis and records the unit-attribution limits of the public ITAAC accessions.

| Source ID | Authority | Configuration | Document | Locator / accession | Use |
|---|---|---|---|---|---|
| SRC-0752 | A | VOGTLE-LAR-17-022-LTOP-HYDRAULIC-PIPING-CONSTRAINTS | NRC Federal Register notice for LAR 17-022, *Addition of a Residual Heat Removal Suction Relief Valve for Low-Temperature Overpressure Protection* | 82 FR 42852-42853, 12-Sep-2017; amendment request `ML17195B047`; issued Unit-3 Amendment 104 / combined SE `ML17332A521` | Plant-specific licensing text establishes that the final dual-relief arrangement uses existing 3-in `RNS-PL-V021` plus added 1-in `RNS-PL-V020`, that V020 has lower capacity and lifts at a lower pressure, and that piping changes were made both to accommodate the added valve and **reduce inlet piping losses**. The same notice states the added valve is ASME Code Section III Class 2 and modified piping is constructed consistently with current RNS piping requirements. Carry inlet-loss sensitivity, valve-size split, relative pressure/capacity ordering and Class-2 boundary as final Vogtle design constraints. The notice does not provide the final V020 numeric set pressure, rated capacity, inlet-line diameter/length/K values, vendor model or exact branch geometry. Do not reverse-engineer those values from the qualitative loss-reduction statement. |
| SRC-0753 | A | VOGTLE-LAR-17-022-LTOP-CVS-V091-CONFIGURATION | NRC Federal Register notice for LAR 17-022 / TS 3.4.14 change | 82 FR 42852-42853, 12-Sep-2017; `ML17195B047`; `ML17332A521` | When the RCS is aligned to the RNS and the RNS relief valves are relied upon for LTOP, the licensing basis adds restrictions to close `CVS-PL-V091` to limit makeup-flow capacity and support reliable relief-valve operation during mass/heat-input transients. The same published basis states that when V091 is open, the RCS is depressurized and an RCS vent of **at least 4.15 in^2** is established. Carry these as mutually distinct licensing/configuration envelopes for the LTOP model, not as operator instructions or an inferred automatic control sequence. Exact Unit-3 interlocks, procedure steps, vent valve/path tags, timing and achieved vent area remain unresolved. |

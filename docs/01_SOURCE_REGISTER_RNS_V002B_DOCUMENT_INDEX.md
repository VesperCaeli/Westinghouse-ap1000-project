Later NRC records establish that AP1000 `VFX` documents in other commodities/modules can be **Released Document Lists (RDLs)** (for example `APP-MT01-VFX-001`, `APP-MT02-VFX-001`, and `APP-Q223-VFX-001`) and that `Z0R` documents in other valve commodities are data-sheet-report/index-type documents. This makes PV01 `VFX-001` and `Z0R-001` high-value **index/release-control retrieval candidates** for locating datasheet, vendor drawing, design-report, test-procedure, or production-document references that may bridge `RNS-PL-V002B` to its individual PV01 datasheet. However, the public 2012 PV01 titles do **not** themselves state that `VFX-001` is an RDL or that `Z0R-001` contains V002B / Datasheet 116, and the same Flowserve inspection has the separately controlled Summer/Vogtle internal-order inconsistency in `SRC-0470`. Use these identifiers as document-control search routes only; do not use the 2012 sales-order/item/casting trail as Vogtle/V002B hardware evidence. |

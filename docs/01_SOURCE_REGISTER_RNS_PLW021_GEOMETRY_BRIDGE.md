# Public Source Register Supplement — Unit 3 RNS PLW-021 Geometry Bridge

This supplement shares the global controlled `SRC-*` namespace. It records the first direct public Unit-3 construction-package bridge tying the RNS LTOP/CVS suction line families to one site isometric and its support-package routes. It does **not** promote individual valves, fittings, spools or supports onto that isometric unless the public record actually prints the tag-to-object relationship.

# Public Source Register Supplement — Vogtle RNS Dual LTOP Relief Configuration

This supplement shares the global controlled `SRC-*` namespace. It records the plant-specific departure that changed the original AP1000 single RNS suction relief-valve arrangement into the final Vogtle parallel `V020` / `V021` LTOP configuration.

| Source ID | Authority | Configuration | Document | Locator / accession | Use |
|---|---|---|---|---|---|
| SRC-0735 | A | VOGTLE-3-4-LAR-17-022-DUAL-LTOP-RELIEF | NRC Federal Register notice and issued combined-license amendments for LAR 17-022, *Addition of a Residual Heat Removal Suction Relief Valve for Low-Temperature Overpressure Protection* | Federal Register 83 FR 5465, FR Doc. 2018-02473; Amendment request `ML17195B047`, supplement `ML17276B537`, combined SE `ML17332A521`; Unit-3 Amendment 104 issued 20-Dec-2017 | NRC states that the approved Vogtle plant-specific change adds a **second RNS suction relief valve in parallel with the existing RNS suction relief valve**, with associated piping changes. The new valve is explicitly `RNS-PL-V020`; the existing valve is `RNS-PL-V021`. The change modified Tier 1/Tier 2, Appendix C and TS 3.4.14 information. Carry this as the configuration-control basis that supersedes the original single-V021 AP1000/Vogtle topology. The amendment notice does not itself print the final local branch line numbers, exact tee locations, vendor model/serial, or measured set pressures. |
| SRC-0736 | A | VOGTLE-DUAL-LTOP-HYDRAULIC-FUNCTION-SPLIT | NRC Federal Register notice of proposed amendment / licensee no-significant-hazards basis for LAR 17-022 | Federal Register 82 FR 42852, 12-Sep-2017, FR Doc. 2017-19214 | The licensing basis identifies the **existing V021 as a 3-inch RNS relief valve** and the **added V020 as a 1-inch RNS relief valve**. The 3-inch valve is sufficient to terminate the identified LTOP transients; the added 1-inch valve was introduced to reduce chatter of the larger valve during low-flow scenarios. NRC's published basis states V020 is designed to the same requirements as V021 but has **lower flow capacity and a lower setpoint pressure**. Carry size and relative hydraulic/setpoint roles as plant-specific design facts. Do not invent the numeric V020 set pressure or production capacity; the public notice only establishes the ordering/relative relationship. |
| SRC-0737 | A | VOGTLE-3-CURRENT-LTOP-OPERABILITY-BASIS | NRC Unit-3 pre-initial-criticality licensing correspondence discussing application of TS 3.4.14 | ADAMS `ML23097A006`, Enclosure E discussion of Mode 4 LTOP requirements | NRC correspondence states that when any cold-leg temperature is at or below 275°F, Vogtle Unit-3 TS 3.4.14 imposes LTOP requirements **requiring two RNS suction relief valves to be operable**, or alternatively the RCS to be depressurized. Use this as post-construction confirmation that the dual-relief configuration is part of the Unit-3 operating licensing basis, not merely an unimplemented design proposal. It does not provide individual valve lift pressures, serials or branch geometry. |
| SRC-0738 | A | VOGTLE-UFSAR-DUAL-RELIEF-TAG-RETENTION | VEGP 3&4 UFSAR Revision 8 Appendix 3I safety-related equipment list | ADAMS `ML19171A061`, Appendix 3I Table 3I.6-3 | The Vogtle UFSAR safety-related equipment population lists **both `RNS-PL-V020` and `RNS-PL-V021` as `RNS Hot Leg Suction Relief`**. This independently confirms retention of both valve tags in the post-amendment plant design. Use as tag/function corroboration, not as a source of valve size, setpoint, model, serial or branch location. |
| SRC-0739 | A | VOGTLE-V021-PV16-DATASHEET-DIRECT | NRC Vogtle Unit-3 PV16 equipment-qualification inspection | ADAMS `ML18226A348`, Section 1A27 | NRC directly maps `RNS-PL-V021` to `APP-PV16-Z0D-105` Revision 4 and its ASME QME-1 test report `5626`, with the PV16 `VBR-001/-002` qualification family and auxiliary-relief-valve data-sheet report. This remains the direct exact-document route for V021. The reviewed population includes several AG-Crosby design-calculation models, but the inspection list does not by itself select one installed model for V021. No equivalent V020 datasheet identifier was exposed in this public sample; V020 must therefore remain a separate retrieval gate rather than inheriting Z0D-105 or V021 hardware. |
| SRC-0740 | A | VOGTLE-RNS-RELIEF-DESIGN-PARAMETER-CHANGE-ROUTE | NRC Vogtle Unit-3 equipment-qualification inspection reviewed licensing-document changes | ADAMS `ML18226A348`, reviewed-document list | NRC identifies `LDCR-2017-114`, *Change to RNS Suction Relief Valve Design Parameters*, dated 16-Feb-2018. This is a high-value controlled route for the post-LAR relief-valve parameter implementation and should be recovered together with LAR 17-022, the current RNS P&ID and both valve data sheets. The public inspection list does not reproduce the parameter values or state whether every parameter applies to both V020 and V021. |

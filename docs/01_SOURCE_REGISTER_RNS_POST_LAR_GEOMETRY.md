# Public Source Register Supplement — Unit 3 RNS Post-LAR Geometry Control

This supplement shares the global controlled `SRC-*` namespace. It records the strongest public drawing-control evidence currently available for reconstructing the final Unit-3 RNS suction/common-header geometry after the plant-specific LTOP change, while keeping actual drawing contents and as-built isometric geometry unresolved until recovered.

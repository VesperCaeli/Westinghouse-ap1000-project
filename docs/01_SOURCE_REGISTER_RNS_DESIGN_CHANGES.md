# Public Source Register Supplement — RNS Design-Change Chronology and Retrieval Routes

This register normalizes major public Westinghouse AP1000 design-change packages that materially affect the RNS physical model, I&C model, support/insulation model, HVAC interfaces, or piping/isometric hierarchy. A DCP title proves that the design changed and provides a controlled retrieval route; it does not by itself prove the exact before/after geometry or the final Vogtle as-built state.

## Control rules

- Chronology matters: later DCPs can supersede geometry or logic implied by earlier ones.
- A DCP title is a retrieval key, not an as-built drawing.
- Standard-plant DCPs do not override Vogtle-specific amendments, site drawings, construction packages, ITAAC records or final test evidence.
- Physical-access DCPs (e.g. ladder interference) are treated as geometry constraints, not merely human-factors notes.
- Insulation, support, HVAC drain, I&C and interlock changes are part of the loop model and must be reconciled before declaring RNS area completeness.

# Public Source Register Supplement — Amendment 104 RNS Tier-1 Line-Table Recovery

This supplement shares the global controlled `SRC-*` namespace. It establishes the issued Vogtle LTOP amendment as a direct configuration-control route to the final RNS piping population without guessing the new relief line identity from legacy isometric numbering.

| Source ID | Authority | Configuration | Document | Locator / accession | Use |
|---|---|---|---|---|---|
| SRC-0765 | A | VOGTLE-3-AMENDMENT-104-RNS-TIER1-LINE-TABLE-CHANGE | NRC notice / issued License Amendment 104, *Addition of a Residual Heat Removal Suction Relief Valve for Low-Temperature Overpressure Protection* | LAR 17-022 request `ML17195B047`, supplement `ML17276B537`, combined SE `ML17332A521`, Unit-3 amendment `ML17332A517`, combined package `ML17332A513`; Federal Register 82 FR 42852 and 83 FR 5465 | The plant-specific amendment explicitly states that the change adding `RNS-PL-V020` in parallel with `RNS-PL-V021`, with necessary piping changes, modifies COL Appendix C / plant-specific Tier-1 **Figure 2.3.6-1 and Tables 2.3.6-1, 2.3.6-2, and 2.3.6-4**. Table 2.3.6-2 is the controlled RNS piping table. Therefore the issued Amendment-104 Appendix-C/Tier-1 package is a direct configuration-control route for determining the final safety-related relief-piping line population and any new/changed line identity associated with V020. The public Federal Register notice identifies the changed table but does not print the amended table rows or line numbers. Do not infer that `RNS-PL-L062` is the new V020 line merely because it co-appears with L040 on the October-2017 PLW-021 work package; recover the issued amended table or an explicit Unit-3 implementation drawing first. |
